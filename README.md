BRIEFING – TEMA: ACESSIBILIDADE PARA IDOSOS EM
PLATAFORMAS DIGITAIS
A instituição FIAP Inclusive está iniciando um movimento para melhorar a
experiência digital de pessoas idosas em ambientes acadêmicos e profissionais.
Muitos usuários da terceira idade enfrentam desafios relacionados a:
● Perda gradual de memória;
● Dificuldades de visão (contraste, leitura de textos pequenos);
● redução da coordenação motora fina
● Menor familiaridade com padrões modernos de navegação;
● Insegurança ao utilizar plataformas digitais;
● Medo de cometer erros irreversíveis;
● Dificuldade em compreender fluxos complexos.
Esses usuários relataram grande dificuldade ao utilizar plataformas
atuais por causa de:
● Excesso de informação na tela;
● Botões pequenos e pouco visíveis;

● Textos com fonte reduzida;
● Baixo contraste entre elementos;
● Navegação pouco intuitiva;
● Ausência de feedback claro após ações;
● Fluxos com muitas etapas e pouca orientação.
Para resolver esse problema, a FIAP Inclusive decidiu desenvolver uma
plataforma chamada SeniorEase, cujo objetivo é facilitar a vida acadêmica e
profissional de pessoas idosas, promovendo autonomia, confiança e inclusão
digital.
Você e seu grupo foram contratados para desenvolver a versão Web e a
versão Mobile, aplicando tudo que aprenderam em:
● Arquitetura (Clean Architecture, Componentização);
● Desenvolvimento Web (React, Angular ou Next.js);
● Desenvolvimento Mobile (Flutter ou React Native);
● Acessibilidade digital;
● Testes, CI/CD e boas práticas.
O Projeto SeniorEase deve conter:
1. Painel de Personalização da Experiência
Um dashboard onde o usuário possa ajustar:
● Tamanho da fonte;
● Nível de contraste;
● Espaçamento entre elementos;
● Simplificação da interface (modo básico / modo avançado);
● Ativação de feedback visual reforçado;
● Confirmação adicional antes de ações críticas.
2. Organizador de Atividades Simplificado
Um sistema de organização com foco em clareza e previsibilidade:

● Lista de tarefas com visual simples e direto;
● Etapas guiadas para execução de atividades;
● Lembretes com linguagem clara;
● Avisos de conclusão com feedback positivo;
● Histórico simples de atividades realizadas.
3. Perfil do Usuário + Configurações Persistentes
Armazenar preferências como:
● Tamanho de fonte escolhido;
● Nível de contraste;
● Modo de navegação (simplificado ou padrão);
● Necessidade de confirmações extras;
● Preferências de lembretes e notificações.
Tecnologias Esperadas
Arquitetura
● Separação clara entre módulos (painel, tarefas, perfil, configurações);
● Comunicação entre microapps, caso utilize.
Desenvolvimento Mobile
● Flutter ou React Native;
● A versão mobile deve manter coerência visual e cognitiva com a
versão Web.
Clean Architecture
● Camada de domínio isolada;
● Casos de uso independentes de UI;
● Adaptadores e interfaces bem definidos.
